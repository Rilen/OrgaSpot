OrgaSpot

A CLI tool for cleaning up and organizing your Spotify account.

Quick Start

npm install
npm start setup
npm start scan-duplicates
npm start validate-taxonomy

CLI Commands

CommandPurpose
setupInitialize lixeira and default playlists
scan-duplicatesFind tracks across multiple playlists
move-duplicatesMove duplicates to lixeira playlist
empty-lixeiraMonthly purge (supports --dry-run)
export-playlistsBackup playlists to CSV/JSON
validate-taxonomyCheck naming convention compliance

Blueprint

Based on the Spotify Account Organization Blueprint:

  • 🧹 [LIXEIRA / REPETIDAS] - Temporary duplicate storage
  • ⭐ [FAVORITOS] - Main tracks in rotation
  • 🎸 [GÊNERO / ESTILO] - Thematic genre playlists
  • 🧠 [FOCO / TRABALHO] - Instrumental/lo-fi for focus
  • 🚗 [ROADTRIP / VIAGEM] - Travel playlists
  • 📦 [ARQUIVO] - Sentimental archive playlists
